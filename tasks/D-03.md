# D-03 · Business registry adapters

## Goal
One interface, Danish and German implementations, returning entity, sector, headcount band and group structure.

## Acceptance criteria
- [x] Adapter interface is stable enough that a third country needs no changes outside its own file
- [x] Rate limits and terms of each registry respected and documented in the adapter
- [x] Missing data returns unknown; the pipeline never guesses a headcount
- [x] A contract test suite runs against every adapter identically

## How this is verified
