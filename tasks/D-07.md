# D-07 · Sub-processor extraction and recursion

## Goal
Extract their sub-processor list, then follow each named vendor to its own list, depth-limited.

## Acceptance criteria
- [x] Depth cap of 3 and a hard node cap, both configurable and both enforced by test
- [x] Cycle detection — vendors do reference each other
- [x] Every edge carries the document and date it came from
- [x] Politeness: one request per host per interval, honouring robots directives

## How this is verified
```bash
pnpm test:integration -- subprocessor-recursion
```

- 2026-09-05 03:05 — A supplier's sub-processor list is found the way a policy is (a link that looks like one in three languages, then the paths such a page lives at, or the home page itself), read line by line for the companies it names (a corporate suffix, an off-site domain or a country makes a line an entry; name, site, country and purpose from the line's cells; the line kept verbatim, tabs and all, so it is a substring of the stored page), and every company with a site is visited in turn, breadth first (packages/scanner/src/subprocessors). The chain is a contract (SupplyChainSchema): nodes with depth and whether their list was read or why not, edges each carrying the list's URL, the moment it was read and the stored evidence, the limits, which limit stopped the walk, how many names the node cap left off, and every request made. Depth cap 3 and node cap 25 by default, both options, both enforced by the walk and refused by the schema, both proved by test (a cap of one reads only the supplier; a cap of four nodes stops and counts the rest). A company already on the chain is a cycle: the edge is kept, marked, and never followed; the supplier that names its own customer back is the test. Politeness is a class with an injected clock: one request per host per interval (the walk's record is checked host by host), robots.txt asked once per host before anything else and read for our own group or everyone with the longest rule winning, a host that refuses everyone gets one request, a host that refuses the list's path is skipped for robots, and respectRobots can be turned off. On the graph (packages/db/src/supply-chain.ts) each company is a vendor node keyed by registry id when the host resolves and by host or name otherwise, at level depth+1, and each list entry an engages edge (new edge kind, vendor to vendor, migration 0020) with document, date, quote and cycle as attributes and the list as evidence; seeding twice is the same rows. The worker walks from every supplier whose agreement was found, behind an option. tests/integration/subprocessor-recursion.test.ts: eight synthetic suppliers, four outcomes, the caps, the cycle, the document and date on every edge, the request record, robots on and off, and the graph read back. Unit: the parser in three languages, the scorer, robots.txt, the interval with a fake clock, the contract's own rules.
