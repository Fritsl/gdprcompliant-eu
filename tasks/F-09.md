# F-09 · Network record and replay

## Goal
Every outbound HTTP, DNS and registry call goes through a recorder; CI replays cassettes and blocks live egress entirely.

## Acceptance criteria
- [x] A CI run with the network cable pulled still passes the whole suite
- [x] Cassettes are committed, human-readable, and redacted of anything resembling a credential
- [x] A missing cassette in CI is a hard error, never a silent live call
- [x] Re-recording is one documented command

## How this is verified
```bash
GC_NETWORK=replay pnpm test:integration
```

## Notes
Without this the suite is flaky and nobody trusts it, which defeats the whole point of the user not testing manually.
