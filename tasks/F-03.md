# F-03 · Core relational schema

## Goal
Tables for tenants, cases, case_events, findings, evidence, remedies, vendors, processing_activities, answers, jurisdictions.

## Acceptance criteria
- [ ] Every table carries tenant_id; every row carries created_at and a source reference
- [ ] case_events is append-only — an UPDATE or DELETE against it raises
- [ ] findings.remedy_id is NOT NULL: a finding without a remedy cannot be inserted (see R-02)
- [ ] evidence rows are immutable and content-addressed by hash
- [ ] Schema diagram committed to docs/schema.md, generated not hand-drawn

## How this is verified
```bash
pnpm test:integration -- schema
```

## Notes
This is the spine. Get the append-only and NOT NULL constraints in now — retrofitting them means a data migration.
