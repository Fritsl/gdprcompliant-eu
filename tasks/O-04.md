# O-04 · Observability

## Goal
Traces, structured logs and metrics for scans, jobs, model calls and verifier rejections.

## Acceptance criteria
- [x] A scan can be reconstructed end to end from its trace
- [x] Model cost and latency tracked per task type
- [x] Verifier rejection rate is a first-class dashboard metric — a sudden drop means the gate broke
- [x] No personal data in logs, asserted by a test that scans log output
