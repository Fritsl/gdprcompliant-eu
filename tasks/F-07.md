# F-07 · Fixture site infrastructure

## Goal
A static server that serves deliberately broken websites from fixtures/sites/<name>/, each with an expected.json naming exactly which findings must and must not be produced.

## Acceptance criteria
- [x] Fixture sites are plain HTML/JS with no build step and no network egress
- [x] Third-party requests are simulated by local hosts mapped through the browser proxy, so no fixture ever reaches the real internet
- [x] expected.json format is documented and validated by a Zod schema
- [x] One reference fixture ships with this task and its expectation passes end to end

## How this is verified
```bash
pnpm test:integration -- fixtures
```

## Notes
Everything in stream S depends on this. It is the ground truth that makes a compliance scanner testable at all.
