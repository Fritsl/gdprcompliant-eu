# A-01 · Case graph schema

## Goal
Activities, data categories, purposes, legal bases, vendors, transfers, risks, controls and evidence as typed rows with provenance.

## Acceptance criteria
- [x] Every node and edge carries source, confidence and timestamp
- [x] Derived facts are distinguishable from asserted facts and from answered facts
- [x] Contradictions are representable and surfaced rather than silently resolved
- [x] The register (G-01) is a pure projection of this graph

## How this is verified
```bash
pnpm test:integration -- case-graph
```
