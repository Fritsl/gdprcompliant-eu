# F-08 · Test harness: projects, gates, reporting

## Goal
Vitest split into unit / integration / e2e / evals / adversarial, each runnable alone, all runnable together, with coverage thresholds that fail the build.

## Acceptance criteria
- [ ] pnpm test:unit runs in under 30 seconds with no database and no network
- [ ] Coverage floor of 85% on packages/findings, packages/rules and packages/remedies; the rest 70%
- [ ] A junit report and an HTML report land in artifacts/ for CI
- [ ] Suites are tagged so the delivery gate (O-05) can require specific ones

## How this is verified
```bash
pnpm test:unit && pnpm test:coverage:check
```
