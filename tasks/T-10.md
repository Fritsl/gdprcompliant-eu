# T-10 · Canary corpus and drift alarm

## Goal
Two hundred real, stable public sites scanned nightly, compared day over day, to catch what fixtures never will.

## Acceptance criteria
- [x] Nightly run produces a diff against yesterday, with unexpected changes raised
- [x] Distinguishes a site that changed from a scanner that changed — by re-running the previous scanner build on the same snapshot
- [x] Sites are public, scanned politely, and the corpus excludes anyone who asks to be excluded
- [x] Alarm has a human owner and a documented triage procedure

## How this is verified
```bash
pnpm run canary:check
```

## Notes
Fixtures prove the scanner does what we designed. The canary proves it still works on the actual internet.
