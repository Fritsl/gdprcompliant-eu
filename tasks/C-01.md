# C-01 · Case object, numbering and ownership

## Goal
A case opens on first scan with a human-quotable number, no account required, claimable later by email.

## Acceptance criteria
- [ ] Number format is CC-YY-XXXX with a country prefix, collision-free, and readable aloud without ambiguity
- [ ] An unclaimed case is reachable only by its unguessable URL and expires if never claimed
- [ ] Claiming requires proving control of an email address at the scanned domain, or an explicit override path
- [ ] Two scans of the same domain by the same owner continue one case rather than opening a second
