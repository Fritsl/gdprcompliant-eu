# C-05 · Re-scan and fix verification loop

## Goal
Press re-check on one finding, re-run only what is needed, and close it if the evidence now says so.

## Acceptance criteria

- [ ] A closed finding that regresses reopens with both dates on the timeline
- [ ] Verification uses the remedy verification method declared in R-01
