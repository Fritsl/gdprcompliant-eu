# C-05 · Re-scan and fix verification loop

## Goal
Press re-check on one finding, re-run only what is needed, and close it if the evidence now says so.

## Acceptance criteria
- [x] Targeted re-verification of a single finding costs a fraction of a full scan
- [x] A closed finding that regresses reopens with both dates on the timeline
- [x] Verification uses the remedy verification method declared in R-01
- [x] Weekly watch job diffs against the last run and raises only genuine changes
