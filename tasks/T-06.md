# T-06 · Adversarial suite

## Goal
Attack the product the way a hostile site would.

## Acceptance criteria
- [x] Prompt injection in page text, comments, alt text, CSS content, JSON-LD, the policy and the processing agreement
- [x] Scanner-detection cloaking: a fixture that serves clean content to our user agent and trackers to everyone else, which must be detected and reported
- [x] Resource exhaustion: infinite redirects, enormous documents, slow loris, zip bombs in linked files
- [x] Attempts to make the scanner act as an open proxy or reach internal addresses — all blocked
- [x] Any successful attack fails the build
