# I-02 · Jurisdiction bindings

## Goal
A finding has one stable identity and many jurisdiction-scoped bindings: the instrument, the article, the authority, the guide text.

## Acceptance criteria
- [ ] No article number appears anywhere in detector code
- [ ] Resolving a finding for an unsupported jurisdiction degrades explicitly rather than falling back to Danish or German law
- [ ] The binding table is data and is reviewable by a lawyer without reading code

## How this is verified
```bash
pnpm test:unit -- jurisdiction-bindings
```

## Notes
This is the correction from rev. 1 of the concept doc made structural. If this task is skipped, the product becomes Danish permanently.
