# S-06 · Cookie classification

## Goal
Classify observed cookies by purpose against a maintained open database, with an explicit unknown bucket.

## Acceptance criteria
- [ ] Unknown cookies are reported as unknown, never guessed into a category
- [ ] Classification source and version recorded on every classification
- [ ] Database refresh is a scheduled job, not a build-time snapshot
