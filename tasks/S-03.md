# S-03 · Consent banner detection and refusal-path automation

## Goal
Find the banner, identify the platform where recognisable, and click through to a genuine refusal however many layers deep it is buried.

## Acceptance criteria
- [ ] Handles the top consent platforms by signature, plus a generic heuristic fallback
- [ ] Follows multi-layer refusal: settings, then toggles off, then save
- [ ] Records the click path taken as evidence, including a screenshot per step
- [ ] Reports honestly when it cannot find a refusal path rather than guessing — that itself is a finding
- [ ] Passes against at least 8 banner fixtures covering different patterns

## How this is verified
```bash
pnpm test:integration -- banner
```

## Notes
The hardest task in phase 2 and the one the whole wedge rests on. Budget accordingly. When uncertain, prefer "could not determine" over a false pass.
