# T-01 · The fixture site suite

## Goal
Twenty-five deliberately broken websites, each isolating known violations, plus clean controls.

## Acceptance criteria
- [ ] Every launch finding type has at least one positive and one negative fixture
- [ ] At least four fixtures are clean sites that must produce zero findings
- [ ] Fixtures cover the awkward cases: lazy-loaded trackers, banners in shadow DOM, iframes, single-page apps, consent stored in localStorage rather than cookies
- [ ] Adding a fixture requires no code change

## How this is verified
```bash
pnpm test:integration -- fixture-suite
```

## Notes
This is the substitute for a human tester. Its coverage is the ceiling on how much anyone can trust the scanner.
