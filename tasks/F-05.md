# F-05 · Multi-tenancy isolation, provable

## Goal
Postgres row-level security plus a per-request tenant context, and a test suite that tries hard to break it.

## Acceptance criteria
- [x] RLS policies on every tenant-scoped table, enabled by default and FORCEd for the app role
- [x] A query without tenant context returns zero rows rather than all rows
- [x] Test suite attempts cross-tenant read, write, join and aggregate — all must fail
- [x] A new table without an RLS policy fails a lint check in CI
