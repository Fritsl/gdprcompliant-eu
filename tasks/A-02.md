# A-02 · Obligations engine and rule language

## Goal
Deterministic, versioned, human-authored rules mapping graph state to duties, each declaring its jurisdiction and citation.

## Acceptance criteria
- [ ] Rules are data, not code, and are reviewable by a non-programmer
- [ ] Evaluation is total and deterministic — same graph, same jurisdiction, same duties, always
- [ ] Every rule cites an article that resolves in the corpus, checked in CI
- [ ] A rule cannot be added without a test case and a citation

## How this is verified
```bash
pnpm test:unit -- rules-engine && pnpm run check:rule-citations
```
