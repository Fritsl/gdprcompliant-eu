# S-14 · Finding assembly and severity

## Goal
Assemble detector output into persisted findings with severity, evidence references, jurisdiction bindings and a resolved remedy.

## Acceptance criteria
- [ ] Severity is computed from a documented rule table, not chosen ad hoc per detector
- [ ] Assembly refuses to persist a finding lacking evidence or a remedy
- [ ] Identical scans produce byte-identical finding sets — determinism is asserted in a test
- [ ] Findings carry a stable id so the same problem is recognisable across re-scans
