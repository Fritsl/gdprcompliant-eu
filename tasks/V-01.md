# V-01 · Status report, generated at any moment

## Goal
A PDF a person can hand to a colleague, a board or an auditor, produced from the case as it stands right now — not only when finished.

## Acceptance criteria
- [x] Status matrix by area, with an explicit not-determined state that is never dressed up as a pass
- [x] Numbered action points carrying owner and effort, ordered the same way the plan is
- [x] Every article the report relies on is quoted in full from the corpus, with a resolvable reference
- [x] Reproducible: the same case at the same point produces an identical document
- [x] Readable printed in greyscale, and carries the case URL so a reader can get to the live version
- [x] Regenerating is one click and always available, including mid-progress

## How this is verified
```bash
pnpm test:integration -- report-render
```

## Notes
The report is the artefact that travels. Someone who never ran the scan will read it first.
