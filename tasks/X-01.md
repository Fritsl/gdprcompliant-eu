# X-01 · Prototype scaffold and design system

## Goal
A Next.js app with the design tokens, type scale, both themes and the locale switch — deliberately minimal, no infrastructure.

## Acceptance criteria
- [ ] Runs with one command from a clean clone; no database, no services, no environment variables
- [ ] Deploys as a static build so Frits can click through it on a phone
- [ ] Tokens, type scale and severity colours defined once, matching the concept document
- [ ] Light and dark both designed, not inverted; severity readable in greyscale
- [ ] A visible PROTOTYPE marker on every screen so no screenshot is ever mistaken for a working product

## How this is verified
```bash
pnpm -F prototype build && pnpm -F prototype test:visual
```

## Notes
Keep it boring and small. F-01 later absorbs this app into the workspace without discarding a single component.
