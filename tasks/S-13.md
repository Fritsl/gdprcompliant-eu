# S-13 · Session replay and fingerprinting detection

## Goal
Detect replay and heatmap tools and, where observable, whether input masking is off on pages containing sensitive fields.

## Acceptance criteria
- [ ] Detects the major replay vendors by network signature and by API surface on the page
- [ ] Reports specifically when replay is active on a page carrying payment or account fields
- [ ] Canvas, font and audio fingerprinting probes detected and reported separately
