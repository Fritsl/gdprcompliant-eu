# V-04 · Advisor safety and limits

## Goal
It is an assistant, not counsel, and the interface has to carry that without becoming a nag.

## Acceptance criteria
- [ ] Not-legal-advice notice present on the surface and on every export, never only in terms
- [ ] Answers rather than deflects: escalation appears only after a genuine attempt, never as a first response to a hard question
- [ ] Case content is untrusted input: a policy or contract that tries to instruct the advisor is rejected
- [ ] Conversations are tenant-scoped and deletable with the case
- [ ] An eval set of 20 questions it should refuse, with the expected refusal shape

## How this is verified
```bash
pnpm test:evals -- advisor-safety && pnpm test:adversarial -- advisor
```
