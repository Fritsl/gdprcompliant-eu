# V-04 · Advisor safety and limits

## Goal
It is an assistant, not counsel, and the interface has to carry that without becoming a nag.

## Acceptance criteria
- [x] Not-legal-advice notice present on the surface and on every export, never only in terms
- [x] Answers rather than deflects: escalation appears only after a genuine attempt, never as a first response to a hard question
- [x] Case content is untrusted input: a policy or contract that tries to instruct the advisor is rejected
- [x] Conversations are tenant-scoped and deletable with the case
- [x] An eval set of 20 questions it should refuse, with the expected refusal shape

## How this is verified
```bash
pnpm test:evals -- advisor-safety && pnpm test:adversarial -- advisor
```
