# V-02 · Case-grounded advisor

## Goal
An assistant holding two things at once — the full legal corpus, and the actual case — so it can answer "we have this, do we need that?"

## Acceptance criteria
- [x] Every answer separates three things: the answer, what this case says, and what the law says
- [x] Facts about the company come from the graph with a link to the evidence, never from the model
- [x] Retrieval is jurisdiction-filtered; a Danish case never gets German law as authority
- [x] Refuses to answer where the case has no evidence, and says which question would settle it
- [x] Answers can be appended to the report, carrying their citations
- [x] Runs on the self-hosted stack — a customer case never leaves the tenant

## How this is verified
```bash
pnpm test:evals -- advisor
```

## Notes
Reuses the corpus and EU inference behind gdprchat.eu. The new part is grounding in the case, which is what makes it worth building rather than pointing people at the existing chat.
