# A-05 · Worker implementations

## Goal
One narrow specialist per task type: crawler, contract reader, registry adapter, researcher, drafter.

## Acceptance criteria
- [x] Each worker has the smallest tool set that does its job and is tested in isolation
- [x] The contract reader has no network access; the crawler has no corpus access
- [x] Workers return claims, never conclusions — assembly and judgement happen elsewhere
