# O-03 · Claim discipline in customer-facing language

## Goal
A reviewed vocabulary: never certificate, never approved, never a named vendor called unlawful.

## Acceptance criteria
- [x] A banned-phrase check runs over all customer-facing content in every locale and fails the build
- [x] Third-party findings are phrased as observable behaviour plus a cited decision
- [x] Disclaimer appears on the case page and every export, not buried in terms

## How this is verified
```bash
pnpm run check:claims
```

## Notes
Cheap to build, expensive to omit. Covers the three legal risks named in §13 of the concept doc.
