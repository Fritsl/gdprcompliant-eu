# F-04 · Shared contracts package (@gc/contracts)

## Goal
Zod schemas for Finding, Evidence, Remedy, Case, CaseEvent, Vendor, Duty, PlannerTask, VerifierVerdict. One definition, used by runtime validation and tests alike.

## Acceptance criteria
- [ ] Every LLM-facing input and output has a Zod schema here and nowhere else
- [ ] JSON Schema is generated from Zod for prompt-side structured output
- [ ] Finding requires: stable id, jurisdiction-scoped bindings, evidence ref, severity, remedy ref
- [ ] Types are exported; no package redefines these shapes locally
