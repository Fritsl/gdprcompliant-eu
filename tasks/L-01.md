# L-01 · Qualification signal and lane routing

## Goal
Score the case from public facts into the self-serve lane or the human lane.

## Acceptance criteria
- [ ] Signals: headcount band, sector, subdomain count, enterprise systems detected, multiple entities, multiple countries, regulated sector
- [ ] Score is explainable, stored, and never shown to the customer
- [ ] Lane assignment changes nothing about what the customer receives — it only decides whether a person reaches out
- [ ] A test asserts no feature is gated by lane
