# L-01 · Qualification signal and lane routing

## Goal
Score the case from public facts into the self-serve lane or the human lane.

## Acceptance criteria
- [x] Signals: headcount band, sector, subdomain count, enterprise systems detected, multiple entities, multiple countries, regulated sector
- [x] Score is explainable, stored, and never shown to the customer
- [x] Lane assignment changes nothing about what the customer receives — it only decides whether a person reaches out
- [x] A test asserts no feature is gated by lane

## How this is verified
```bash
pnpm test:unit -- lane-routing
```

## Notes
The last acceptance line is the rule from §08 of the concept doc. Encode it as a test so it cannot erode.
