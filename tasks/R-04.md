# R-04 · Remedy resolver and solution catalogue

## Goal
Given a finding and a context, pick the cheapest remedy that genuinely closes it, honestly.

## Acceptance criteria
- [ ] A free self-service fix always outranks a paid one when both would close the finding
- [ ] Anything of ours is flagged as ours in the returned object, not only in the UI
- [ ] partner_alternative returns at least two options or degrades to no_solution
- [ ] Resolution is deterministic and explained — the reason is stored, not just the choice

## How this is verified
```bash
pnpm test:unit -- remedy-resolver
```

## Notes
The honesty rules from the concept doc live here as tests, so they cannot quietly erode later.
