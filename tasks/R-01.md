# R-01 · Remedy schema and catalogue store

## Goal
Remedies as first-class content: kind, jurisdiction scope, effort, the actual instruction, and what closes the finding.

## Acceptance criteria
- [ ] Kinds are exactly: self_fix, generated_artefact, our_product, partner_alternative, no_solution
- [ ] Remedies are jurisdiction-scoped and locale-scoped like findings
- [ ] Each remedy declares a verification method so "did this actually fix it" is machine-checkable
- [ ] Catalogue is versioned; a remedy change is auditable

## How this is verified
```bash
pnpm test:unit -- remedy-schema
```
