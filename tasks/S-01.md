# S-01 · Browser pool with clean-profile isolation

## Goal
Playwright Chromium pool where every pass gets a genuinely fresh profile — no cookies, no storage, no service workers, no cache carried across passes.

## Acceptance criteria
- [x] A test proves pass N cannot observe any state written during pass N-1
- [x] Concurrency limit, per-page timeout, and hard kill on hang
- [x] Realistic viewport, locale and timezone, configurable per scan target
- [x] Memory stays flat across 200 sequential scans

## How this is verified
```bash
pnpm test:integration -- browser-pool
```

## Notes
Profile bleed silently invalidates the entire three-pass diff. Prove isolation before building on it.
