# O-02 · Retention and deletion jobs

## Goal
Everything the system holds has a declared lifetime and a job that enforces it.

## Acceptance criteria
- [ ] Every table declares a retention rule; a table without one fails a CI check
- [ ] Unclaimed cases and their evidence expire automatically
- [ ] Deletion is verified by a test that asserts blobs are gone, not only rows

## How this is verified
```bash
pnpm test:integration -- retention
```
