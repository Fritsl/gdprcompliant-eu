# T-04 · Schema conformance for every model output

## Goal
No model output enters the system unvalidated, and malformed output has a defined behaviour.

## Acceptance criteria
- [ ] Every model call site validates against its Zod schema
- [ ] Fuzzed and truncated responses are handled deterministically — retry once, then fail loudly
- [ ] A test enumerates model call sites and fails if any lacks validation

## How this is verified
```bash
pnpm test:unit -- schema-conformance
```
