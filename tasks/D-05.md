# D-05 · App listing and data-safety comparison

## Goal
Find the mobile app if any, read its declared data collection, compare against the website policy.

## Acceptance criteria
- [x] Contradictions between store declaration and website policy produce a finding quoting both
- [x] Absence of an app is a clean negative, not an error

## How this is verified
```bash
pnpm test:integration -- app-listing
```
