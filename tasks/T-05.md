# T-05 · Behavioural eval sets

## Goal
Fixed scenario sets with expected judgements for the planner, the verifier, the policy reader and the DPA reader.

## Acceptance criteria
- [ ] Each set has at least 20 labelled scenarios with documented reasoning
- [ ] Pass thresholds are declared per set and enforced in CI
- [ ] Results are tracked over time so a prompt change that degrades quality is visible
- [ ] Evals run against the self-hosted model configuration, not only a hosted one
