# I-01 · Translatable content model

## Goal
Findings, remedies and guides as structured content objects with locale variants — never hardcoded strings.

## Acceptance criteria
- [x] A missing translation falls back to English visibly, and is reported, never silently
- [x] Adding a locale requires no code change outside content files
- [x] A CI check lists untranslated content per locale

## How this is verified

pnpm run check:i18n-coverage
