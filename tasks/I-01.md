# I-01 · Translatable content model

## Goal
Findings, remedies and guides as structured content objects with locale variants — never hardcoded strings.

## Acceptance criteria
- [ ] A missing translation falls back to English visibly, and is reported, never silently
- [ ] Adding a locale requires no code change outside content files
- [ ] A CI check lists untranslated content per locale

## How this is verified
```bash
pnpm run check:i18n-coverage
```
