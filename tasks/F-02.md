# F-02 · Postgres + pgvector, Drizzle, migration harness

## Goal
docker-compose brings up Postgres 16 with pgvector; Drizzle migrations apply and roll back; tests get a disposable schema per run.

## Acceptance criteria
- [x] docker compose up -d gives a working database with the vector extension enabled
- [x] pnpm db:migrate is idempotent; running it twice is a no-op
- [x] Each vitest integration file gets an isolated schema, dropped afterwards, so tests can run in parallel
- [x] No test ever touches a developer database by default — the connection string must be explicit

## How this is verified
```bash
pnpm db:migrate && pnpm test:integration -- db
```
