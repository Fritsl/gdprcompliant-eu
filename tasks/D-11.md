# D-11 · Crawl etiquette and scan authorisation

## Goal
Rate limits, honest bot identity, published behaviour, and a rule about who may run a deep scan on whom.

## Acceptance criteria
- [x] Named user agent with a URL explaining exactly what the scanner does
- [x] Per-host and per-domain rate limits enforced centrally, not per collector
- [x] Deep scan of a third party requires either domain control or a documented public-interest path
- [x] A published page describes the scanner behaviour, and a test asserts the code matches the page
- [x] Never authenticates, never submits, never follows a link requiring consent to terms

## How this is verified
```bash
pnpm test:integration -- crawl-etiquette
```
