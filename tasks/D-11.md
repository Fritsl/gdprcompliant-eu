# D-11 · Crawl etiquette and scan authorisation

## Goal
Rate limits, honest bot identity, published behaviour, and a rule about who may run a deep scan on whom.

## Acceptance criteria
- [ ] Named user agent with a URL explaining exactly what the scanner does
- [ ] Per-host and per-domain rate limits enforced centrally, not per collector
- [ ] Deep scan of a third party requires either domain control or a documented public-interest path
- [ ] A published page describes the scanner behaviour, and a test asserts the code matches the page
- [ ] Never authenticates, never submits, never follows a link requiring consent to terms

## How this is verified
```bash
pnpm test:integration -- crawl-etiquette
```
