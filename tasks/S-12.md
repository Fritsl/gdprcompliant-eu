# S-12 · Security surface checks

## Goal
The Article 32 surface a stranger can see: TLS, HSTS, headers, mixed content, downgrade on form posts, referrer leakage, exposed paths.

## Acceptance criteria
- [ ] Exposed-path probing is limited to a documented, conservative list and respects robots directives
- [ ] Never attempts authentication, never sends a payload, never enumerates users beyond what a single public endpoint returns
- [ ] Each check maps to a finding with a remedy that is a concrete config change
