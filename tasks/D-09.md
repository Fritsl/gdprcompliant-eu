# D-09 · Sector inference and question selection

## Goal
Narrow two hundred possible questions to the handful whose answers actually branch the assessment.

## Acceptance criteria
- [ ] Question selection is driven by the rules engine, not by the model
- [ ] Each candidate question declares which duties its answer would resolve
- [ ] Selection is explainable — the case can show why it asked what it asked
- [ ] Never asks something already derivable from evidence already held

