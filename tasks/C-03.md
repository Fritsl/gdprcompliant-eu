# C-03 · Case state machine

## Goal
opened → assessed → working → documented → watched, with explicit transitions and no way to skip backwards silently.

## Acceptance criteria
- [ ] Transitions are declared in one place and tested exhaustively
- [ ] State is derived from evidence, not set by hand — reaching documented requires the artefacts to exist
- [ ] A case never reaches a terminal state; watched is the resting state

## How this is verified
```bash
pnpm test:unit -- case-state
```
