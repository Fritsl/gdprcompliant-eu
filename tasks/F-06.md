# F-06 · Durable job queue and resumability

## Goal
pg-boss on the same Postgres, typed job definitions, and proof that a killed worker resumes without losing or duplicating work.

## Acceptance criteria
- [ ] Jobs are declared with a Zod payload schema and fail fast on malformed input
- [ ] A test kills a worker mid-job and asserts the job completes exactly once on restart
- [ ] Long jobs checkpoint progress so a scan surviving a restart does not begin again from zero
- [ ] Dead-letter queue with a visible reason string

## How this is verified
```bash
pnpm test:integration -- queue
```

## Notes
pg-boss over Temporal deliberately — see PLAN.md §Decisions. Keep the job interface narrow so swapping later is contained.
