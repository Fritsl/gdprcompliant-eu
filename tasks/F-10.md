# F-10 · Config, secrets and the EU-only constraint

## Goal
Typed config loading with startup validation, and an explicit allowlist of external endpoints the system may ever contact.

## Acceptance criteria
- [ ] Missing or malformed config fails at boot with a readable message, never at first use
- [ ] Every outbound host is declared in config with a purpose and a jurisdiction
- [ ] A test asserts no code path can reach a host outside the allowlist
- [ ] Model endpoints are configured as OpenAI-compatible base URLs so the self-hosted stack drops in

## How this is verified
```bash
pnpm test:unit -- config
```
