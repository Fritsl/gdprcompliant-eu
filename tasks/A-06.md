# A-06 · The planner

## Goal
Model-driven planning over the open duties, constrained to the task catalogue and to a budget.

## Acceptance criteria
- [x] Cannot emit anything outside the catalogue; malformed plans are rejected and retried once, then escalated
- [x] Explains its choice per task in a line a human can read on the case
- [x] Behavioural evals: on 20 fixed scenarios it selects a sensible next task ≥ 90% of the time
- [x] Deterministic replay: given the same graph and seed, plans are reproducible for debugging

## How this is verified
```bash
pnpm test:evals -- planner
```
