# A-07 · The verifier gate

## Goal
Nothing enters the graph without an evidence pointer and, for legal claims, a citation that actually resolves.

## Acceptance criteria
- [ ] Quoted evidence is confirmed by exact substring match against the stored source, in code, not by a model
- [ ] Citations are resolved against the corpus for the stated jurisdiction; an unresolvable citation rejects the claim
- [ ] A second-pass model check runs on claims that pass the mechanical checks
- [ ] Rejections are recorded with a reason and are visible in an internal review queue
- [ ] Poisoned-input suite: 50 deliberately false or fabricated claims, ≥ 98% rejected

## How this is verified
```bash
pnpm test:evals -- verifier && pnpm test:adversarial -- claim-poisoning
```

## Notes
Scheduled in phase 2 despite being agent work, because S-10 needs it. It is the single most load-bearing safety component.
